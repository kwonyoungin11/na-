# 데스크톱 전술 HUD 목업

## 화면 인벤토리
- 메인 지휘판 (`MainWindow`)
- 분석 보드 (`ChartPopupWindow`)

## 메인 지휘판 와이어프레임
```text
+--------------------------------------------------------------------------------------+
| 상단 명령바: 제목 · 상태칩 · 새로고침 · 분석 보드 · 자동수집 · 중지                 |
+----------------------+---------------------------------------------+-----------------+
| 좌측 필터 레일       | 중앙 전술 보드                               | 우측 인사이트   |
| - 기간/사정률        | - 전술 보드 진입 카드                        | - 현재 필터     |
| - 지역               | - KPI 카드                                  | - 선택 업체     |
| - 키워드/발주처      | - 공고 리스트                               | - 저장 파일     |
| - 경쟁업체 선택      | - 상위 경쟁업체 / 사정률 Top30 / 작전 메모   | - 실시간 이벤트 |
+----------------------+---------------------------------------------+-----------------+
| 하단 상태바: 진행률 · 저장 경로                                                     |
+--------------------------------------------------------------------------------------+
```

## 분석 보드 와이어프레임
```text
+--------------------------------------------------------------------------------------+
| 상단 명령바: 제목 · 기간 · 정밀도 · 최소/최대 사정률                                |
+----------------------+---------------------------------------------+-----------------+
| 좌측 필터 레일       | 중앙 분석 보드                               | 우측 브리핑     |
| - 전역 범위 요약     | - 개요 산점도                                | - 마지막 동기화 |
| - 업체 검색          | - 추세 차트                                  | - 선택 업체     |
| - 경쟁업체 선택      | - 분포 차트                                  | - 공고 리스트   |
| - 자동 반영 안내     |                                             | - 변동 피드     |
+----------------------+---------------------------------------------+-----------------+
| 하단 조작 상태바: 인터랙션 가이드 · 정밀도 · 현재 필터                               |
+--------------------------------------------------------------------------------------+
```

## 설계 원칙
- 메인창은 브리핑/모니터링, 분석창은 정밀 탐색으로 역할을 분리한다.
- 같은 기능 버튼은 한 곳에만 둔다.
- 차트는 중앙 주인공, 로그는 우측 또는 하단 조연으로 내린다.
- 사용자가 5초 안에 다음 행동(필터 조정 / 분석 보드 진입)을 결정할 수 있어야 한다.
