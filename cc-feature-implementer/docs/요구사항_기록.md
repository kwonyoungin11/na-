# 사용자 요구사항 기록

## 핵심 목표

- 나라장터 원천 API 데이터로 통합 파일을 생성한다.
- `/mnt/a/c/nara-workspace/master/전체_통합_데이터.xlsx` 형식의 주요 컬럼을 유지한다.
- 참여업체 **모든 정보**와 **낙찰정보**를 포함한다.

## 필수 컬럼

1. 공고번호
2. 공고명
3. 발주처
4. 지역제한
5. 순위
6. 업체명
7. 개찰일시
8. 투찰일시
9. 투찰금액
10. 기초대비사정률
11. 예정가격
12. 기초금액
13. 사정률
14. 발주처투찰률

## 추가 요구

- 키워드 대상(발굴조사, 시굴조사, 시굴, 발굴, 지표조사) 공고를 우선 수집한다.
- 공고별 참여업체 전체 목록(순위/투찰금액/투찰률/비고 등)을 빠짐없이 저장한다.
- 낙찰 관련 값(낙찰하한율, 낙찰하한가, 낙찰여부/비고)을 함께 제공한다.

(기록 시각: 2026-02-25)
