# 데스크톱 전문화 리뷰

## 제거/축소한 문제
- 중복된 분석창 진입 문구와 버튼 노출 축소
- 메인창의 패널 나열형 정보 구조 축소
- 분석창의 탭 중심 구조를 전술 보드 중심 구조로 단순화
- 업체 선택 패널을 플로팅 팝업 형태에서 고정 레일로 변경

## 이번 개편의 핵심
- 상단 명령바 + 좌측 필터 레일 + 중앙 핵심 보드 + 우측 인사이트 레일 + 하단 상태바 구조 적용
- 메인창은 브리핑/모니터링, 분석창은 정밀 탐색 역할로 분리
- 어두운 HUD 톤과 앰버 강조색으로 시각 위계 강화

## 아직 남은 과제
- 메인창과 분석창에 조건부 우위/금지구간 카드 직접 연결
- 차트 내부 색상도 다크 HUD 토큰과 더 일치시키기
- 우측 레일을 실제 crowding/collision 분석 JSON과 연결하기
