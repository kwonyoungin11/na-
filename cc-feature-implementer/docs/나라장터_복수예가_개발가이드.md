# 나라장터 복수예가 개발 가이드 (실전)

## 1) 먼저 알아야 할 핵심 지식
- **공고/개찰/예비가격 데이터는 API가 분리**되어 있습니다. 1개 API로 끝나지 않습니다.
- `bidNtceNo + bidNtceOrd (+ bidClsfcNo + rbidNo)` 조합으로 데이터를 연결합니다.
- 복수예가 분석용 핵심 값은 `예정가격(plnprc)`, `기초금액(bssamt)`, `낙찰하한율(sucsfbidLwltRate)`, `투찰금액(bidprcAmt)`입니다.

## 2) 필수 API 조합 (용역 기준)
1. 개찰결과 목록: `getOpengResultListInfoServcPPSSrch`
   - 개찰완료 공고 목록 수집
2. 개찰완료 상세: `getOpengResultListInfoOpengCompt`
   - 업체별 순위/투찰금액/투찰일시 수집
3. 예비가격 상세: `getOpengResultListInfoServcPreparPcDetail`
   - 예정가격, 기초금액 수집
4. 입찰공고 상세: `getBidPblancListInfoServc`
   - 낙찰하한율 수집
5. 참가가능지역: `getBidPblancListInfoPrtcptPsblRgn`
   - 지역제한(전국/지역명) 수집

## 3) 엑셀 계산 로직(현재 구현)
- 예가대비투찰률 = `투찰금액 / 예정가격 * 100` (API 값 우선)
- 기초대비투찰률 = `투찰금액 / 기초금액 * 100`
- 사정률 = `예정가격 / 기초금액 * 100`
- 낙찰하한가 = `예정가격 * 낙찰하한율 / 100`
- 기초대비사정률 = `기초대비투찰률 / 낙찰하한율 * 100`
- 낙찰하한가차이 = `투찰금액 - 낙찰하한가`

> 참고: 아이건설넷 엑셀과 **완전히 동일한 값**을 내려면 내부 보정규칙(소수점 처리, 예외 필터, 순위처리)이 추가로 필요할 수 있습니다.

## 5) 데이터 품질 체크
- `resultCode`가 `00`인지 확인
- 공고별로 `예정가격/기초금액` 누락건 비율 확인
- `순위=-1` 건(낙찰하한 미달 등) 처리 규칙을 별도로 정의
