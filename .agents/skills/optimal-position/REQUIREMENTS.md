# 최적 투찰 위치 추천 - 요구사항

## 분석 구조

1. **2년 전체**: 업체 고정자리 탐색
2. **1년**: 변하지 않는지 확인
3. **6개월, 3개월**: 변하지 않는 자리 탐색, 변했다면 어디로
4. **최종 분석**: 3개월 + 1개월 데이터로 추천

## 점수 계산 (가중 합산)

```
종합점수 =
  가림막점수 × 35% +
  안전마진점수 × 30% +
  경쟁밀도점수 × 20% +
  역사적승률 × 15%
```

## 핵심 원칙

- **하드코딩 없음**: 오직 데이터로만 계산
- **예측 없음**: 복수예가입찰은 예측 불가, 분석만
- **내 업체 제외**: 동국문화재연구원 (MY_COMPANY)
